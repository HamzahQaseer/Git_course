# مشروع نظام دردشة P2P

## وصف المشروع
نظام دردشة نظير إلى نظير (Peer-to-Peer) يقوم بتمكين الاتصال المباشر بين المستخدمين دون الحاجة إلى خادم مركزي. هذا النظام يُعد مناسبً�� للتطبيقات التي تتطلب الخصوصية أو العمل في بيئات محدودة الشبكة مثل الشبكات المحلية.

### الفكرة العامة:
نظام يتيح للمستخدمين إنشاء اتصال مباشر لنقل الرسائل بشكل آمن وفعّال.

### المزايا:
1. عدم الحاجة لخادم مركزي (Decentralized).
2. سهولة الاستخدام.
3. الاعتماد على بروتوكولات TCP/UDP للاتصال.
4. قابلية التوسع ضمن الشبكات المحلية.
   
## مكونات النظام:
1. **واجهة المستخدم (CLI):** واجهة نصية بسيطة لإرسال واستقبال الرسائل.
2. **إدارة الاتصال:** إنشاء اتصال بين طرفين باستخدام مكتبة Sockets في لغة البرمجة C.
3. **نقل الرسائل:** تبادل البيانات بشكل آمن وفعّال.

## المتطلبات
- مترجم لغة C (مثل GCC).
- نظام تشغيل يدعم مكتبة Sockets (مثل Linux/Windows).
- شبكة محلية أو اتصال إنترنت مباشر (P2P).

## كيفية التشغيل:
1. قم بتجميع الكود باستخدام الأمر:
   ```bash
   gcc -o chat peer_to_peer_chat.c
   ```
2. شغل البرنامج عبر كتابة:
   ```bash
   ./chat
   ```
3. أدخل عنوان IP الخاص بالطرف الآخر ورقم المنفذ لبدء الدردشة.
   
## المميزات التقنية:
- استخدام مكتبة Sockets لاتصال P2P.
- بروتوكول TCP لضمان نقل البيانات بشكل موثوق.
- دعم رسائل نصية فورية.

## الخاتمة:
يهدف هذا المشروع إلى تقديم مثال بسيط وفعّال لنظام دردشة نظير إلى نظير باستخدام الحد الأدنى من الموارد مع الاتكال على لغة C لتوفير اتصال مستقر وآمن.
